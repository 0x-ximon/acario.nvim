## Installation

You can install it via your favorite plugin manager. Here's an example using [Lazy.nvim](https://github.com/folke/lazy.nvim):

```lua
return {
    "0x-ximon/acario.nvim",
    name = "acario",
    lazy = false,
    priority = 1000,
}
```

> [!IMPORTANT] Neovim Version
> This colorscheme requires Neovim 0.8 or higher.
